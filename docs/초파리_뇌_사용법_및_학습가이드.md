# 초파리 뇌 시뮬레이터 사용법 & 초파리 뇌 학습(Learning) 및 VLA 강화학습 적용 가이드

이 문서는 수컷 초파리 뇌 배선 지도(MaleCNS 2026) 기반 시뮬레이터의 상세 사용법, 뇌 신경망 학습(Training) 적용 방법, 웹 호스팅 및 무설치 배포 방안, 그리고 VLA(Vision-Language-Action) 모델과의 강화학습 연동 가능성을 종합적으로 정리한 가이드입니다.

## 1. 프로그램 개요 및 구성 요소별 사용법

본 프로젝트는 2026년 9월 공개된 수컷 초파리 중추신경계 배선도(MaleCNS v1.0, 뉴런 166,700개, 시냅스 2,753,975개)를 브라우저 상에서 Leaky Integrate-and-Fire(LIF) 물통 모델로 실시간 구동하는 물리 AI 실험실입니다.

### 📁 구성 요소
1. **`fly-bodies/` (3D Physical AI 로봇 실험실)**
   - **특징**: 유니트리 Go1 로봇 개, 마이크로덕, 유니트리 G1 휴머노이드, 로봇 사커 킷 등을 3D 브라우저 MuJoCo physics engine과 ONNX runtime으로 구동.
   - **사용법**: 
     - 탭을 클릭하여 원하는 로봇 몸체(Go1, G1, Duck 등)와 지형 환경(평지, 장애물 상자, 경사로 등)을 선택.
     - 초파리 뇌의 감각 입력(시각, 냄새, 기계 감각)이 중앙 복합체(Central Complex)를 거쳐 로봇 하위 강화학습 보행 정책으로 전달되는 과정 관찰.
2. **`fly-walk/` (2D 초파리 + 3D 뇌 실시간 발화 시뮬레이터)**
   - **특징**: 무설치 HTML/JS로 2D 경기장 속 초파리 이동과 3D 뇌 신경 발화를 동시 관찰.
   - **사용법**:
     - 캔버스를 클릭하여 바나나(먹이) 위치 지정.
     - 더듬이 상태 제어 (정상, 왼쪽 제거, 오른쪽 제거, 반전)를 통해 향성(Taxis) 행동 변화 분석.
     - 시냅스 차단(Cut) 버튼으로 뇌 연결 온/오프 실험.
3. **`fly-duck/` (마이크로덕 3D 뇌 절제 및 시냅스 비교 실험실)**
   - **특징**: 2024 암컷 뇌 vs 2026 수컷 뇌 비대칭성 및 시냅스 절제 실험.
4. **`notebook/초파리_뇌지도_실습.ipynb` (Colab 분석 노트북)**
   - **특징**: 구글 코랩에서 Python/Pandas/PyArrow로 뇌 배선 표 탐색 및 냄새 경로 뉴런 연결 분석.

## 2. 초파리 뇌 학습(Learning) 적용 방법

현재 프로그램의 초파리 뇌는 **고정된 배선 구조(Static Connectome Graph)** 상에서 LIF 물통 모델로 발화(Spike)만 시뮬레이션하며, 가중치 자체는 학습되지 않는 상태입니다. 이를 실제 학습 가능한 모델로 전환하는 방법은 크게 두 가지입니다.

### 🅰️ 방법 1: 생물학적 시냅스 가소성 (Synaptic Plasticity) 적용 (온라인/브라우저 가능)

#### 1. STDP (Spike-Timing-Dependent Plasticity) 구현
전시냅스 뉴런($i$)과 후시냅스 뉴런($j$)의 발화 시간차 $\Delta t = t_j - t_i$에 따라 시냅스 가중치 $w_{ij}$를 실시간 업데이트합니다.

$$\Delta w_{ij} = \begin{cases} A_+ \exp(-\Delta t / \tau_+) & \text{if } \Delta t > 0 \text{ (LTP: 장기 강화)} \\ -A_- \exp(\Delta t / \tau_-) & \text{if } \Delta t < 0 \text{ (LTD: 장기 약화)} \end{cases}$$

#### 2. 도파민 변조 3-요소 STDP (Reward-Modulated STDP)
초파리 버섯체(Mushroom Body, MB)의 냄새 학습 메커니즘을 모방합니다.
- 케니언 세포(Kenyon Cells)와 버섯체 출력 뉴런(MBONs) 간 시냅스에 **도파민 뉴런(DANs)의 보상 신호(Reward $R$)**를 곱하여 학습시킵니다.
- **업데이트 식**: $\Delta w_{ij}(t) = \eta \cdot R(t) \cdot E_{ij}(t)$ ($E_{ij}$는 자격 자국 Eligibility Trace).

#### 3. 브라우저 Web Worker (`brain-worker.js`) 내 적용 예시 코드:
```javascript
// Web Worker 내 시냅스 가중치 학습 모듈 예시
const lastSpikeTime = new Float32Array(neuronCount); // 각 뉴런의 마지막 발화 시간
const weights = connectome.weights; // 시냅스 가중치 배열

function updateSynapsePlasticity(preId, postId, currentTime, rewardSignal = 0) {
  const dt = currentTime - lastSpikeTime[postId];
  const tau = 20.0; // ms
  const lr = 0.001;
  
  if (dt > 0 && dt < 50) {
    // LTP (장기 강화) + 도파민 보상 변조
    const dw = lr * Math.exp(-dt / tau) * (1 + rewardSignal);
    weights[synapseIndex] = Math.min(maxWeight, weights[synapseIndex] + dw);
  } else if (dt < 0 && dt > -50) {
    // LTD (장기 약화)
    const dw = lr * Math.exp(dt / tau);
    weights[synapseIndex] = Math.max(minWeight, weights[synapseIndex] - dw);
  }
}
```

### 🅱️ 방법 2: SNN Surrogate Gradient BPTT 오프라인 학습 (PyTorch / Python)

1. **SNN 프레임워크 선택**: `snnTorch`, `SpikingJelly`, 또는 `Nengo`.
2. **Surrogate Gradient (대리 미분) 적용**:
   LIF 뉴런의 Step 함수 $\Theta(V - V_{th})$는 미분값이 0이므로, Fast Sigmoid나 ArcTan 대리 미분 함수를 채택하여 역전파(Backpropagation)를 수행합니다.
3. **학습 절차**:
   - MaleCNS 2026의 인접 행렬(Adjacency Matrix)을 PyTorch 핑거프린트 텐서로 로드.
   - 입력 감각 뉴런에 시각/냄새 텐서를 입력하고, 출력 운동 뉴런의 Spike Rate와 목표 행동 간의 Cross-Entropy / MSE Loss 계산.
   - PyTorch `optimizer.step()`으로 시냅스 가중치 행렬 $W$ 업데이트.
   - 학습 완료된 $W$를 `.bin` 바이너리 파일로 내보내어 브라우저 JS 시뮬레이터에 교체 적용.

## 3. Antigravity 없이 웹상에 올리고 타 기기(컴퓨터/모바일)에서 동작시키는 방법

Antigravity IDE를 열지 않고 스마트폰, 태블릿, 다른 PC의 브라우저에서 독립적으로 동작하게 하는 2가지 방법입니다.

### 1️⃣ 로컬 네트워크(동일 Wi-Fi / 모바일 핫스팟) 접속
PC에서 실행 후 외부 스마트폰이나 다른 컴퓨터에서 접속합니다.

- **`fly-bodies` 실행**:
  ```bash
  cd fly-bodies
  npm run dev -- --host 0.0.0.0 --port 3000
  ```
- **`fly-walk` 실행**:
  ```bash
  cd fly-walk
  python -m http.server 8000 --bind 0.0.0.0
  ```
- **접속 방법**: PC의 IP 주소(예: `http://192.168.0.15:3000` 또는 `http://192.168.0.15:8000`)를 스마트폰 브라우저에 입력.

---

### 2️⃣ 클라우드 정적 웹 호스팅 (24시간 무상 외부 서비스)

개발 서버 없이 웹상에 완벽히 올려 누구나 접속하게 만듭니다.

#### A. GitHub Pages 배포
1. `fly-bodies/vite.config.js`에 `base: './'` 설정 (이미 완료됨).
2. 빌드 실행: `cd fly-bodies && npm run build`
3. 생성된 `dist/` 폴더의 내용을 GitHub 저장소의 `gh-pages` 브랜치에 푸시.

#### B. Hugging Face Static Space 배포 (추천)
1. Hugging Face에서 새 Space 생성 (`SDK: Static` 선택).
2. `fly-bodies/dist` 폴더 내부의 모든 파일(`index.html`, `assets/` 등)을 Drag & Drop 업로드.
3. 몇 초 내에 전 세계 어디서든 모바일/PC 접속 가능한 URL 생성.

#### C. Vercel / Netlify 배포
- GitHub 저장소를 Vercel / Netlify에 연동.
- Build Command: `npm run build`
- Output Directory: `fly-bodies/dist` (또는 `fly-walk` 정적 폴더) 지정 시 자동 배포 URL 제공.

## 4. VLA(Vision-Language-Action)와 초파리 뇌 강화학습 연동 및 판단

### 🔍 VLA 파운데이션 모델이란?
VLA(예: OpenVLA, RT-2, Octo)는 카메라 영상(Vision)과 자연어 명령(Language: "테이블 위 바나나를 향해 이동해라")을 입력받아 로봇의 관절 제어 신호(Action)를 직접 출력하는 70억(7B) 이상의 거대 멀티모달 모델입니다.

---

### 💡 VLA + 초파리 뇌 강화학습 통합 구조 설계

```
[카메라 영상 / 자연어 명령] 
          │
          ▼
[VLA Vision-Language Encoder] ──(고차원 특성 임베딩)──┐
                                                      ▼
                                       [초파리 뇌 감각 뉴런 레이어]
                                       (ALPN / Visual Lobula Neurons)
                                                      │
                                                      ▼
                                       [Central Complex & MB SNN]
                                       (166,700 뉴런 LIF 시뮬레이션)
                                                      │
                                                      ▼
                                       [Descending Motor Neurons]
                                                      │
          ┌───────────────────────────────────────────┴───────────────────────────────────────────┐
          ▼                                                                                       ▼
[로봇 관절 제어 (Go1/G1/Duck)]                                                   [도파민 보상 피드백 (DANs)]
                                                                                  (Dopaminergic Reward STDP)
```

1. **입력 변환 계층 (Encoder-Sensory Bridge)**:
   VLA의 이미지/텍스트 Transformer Latent Vector를 초파리의 시각 뉴런(Lobula Neurons) 및 냄새 뉴런(ALPN)의 발화 빈도(Spike Rate)로 변환.
2. **초파리 뇌 처리 계층 (Connectome Core SNN)**:
   Central Complex(CX, 방향 제어)와 Mushroom Body(MB, 메모리/보상)가 VLA 표현형 신호를 수신하여 3D 시냅스 회로를 거쳐 통합.
3. **강화학습 (Reinforcement Learning)**:
   - **알고리즘**: PPO (Proximal Policy Optimization) 또는 Reward-Modulated STDP.
   - **보상 함수**: 로봇이 VLA 지시어를 완수하고 장애물을 회피할 때 도파민 뉴런(DANs)에 양(+)의 보상 전달.

### 🎯 최종 종합 판단 및 구현 로드맵

> **[판단 결론]**: 브라우저 JS 상에서 **VLA 모델과 초파리 뇌를 직접 "실시간 강화학습"시키는 것은 연산/메모리 한계로 불가**하지만, **"서버 훈련 ➔ 브라우저 추론 배포" 2단계 오프로딩 구조로는 100% 적용 가능**합니다.

#### 추천 3단계 실행 로드맵:
1. **1단계 (서버 훈련)**: GPU 서버 환경에서 PyTorch + `snnTorch` + OpenVLA 라이브러리를 결합하여 VLA-초파리 뇌 강화학습 진행.
2. **2단계 (모델 경량화 및 경원 변환)**: 훈련 완료된 초파리 뇌 시냅스 가중치 $W$와 VLA 추론기를 ONNX / WebNN 포맷으로 Quantization(INT8) 변환.
3. **3단계 (웹/모바일 배포)**: 변환된 가중치 바이너리를 본 프로젝트의 `fly-bodies` (ONNX Web / MuJoCo WASM) 엔진에 탑재하여 다른 기기에서 완벽 구동.
